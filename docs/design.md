# 《灰烬王冠》制作规格书（内部）

GBA《火焰纹章》式中文回合制战棋。浏览器运行，纯原生 JS（ES Module）+ Canvas2D，WebGL 负责放大和 CRT 滤镜。
所有美术由 Python(PIL) 脚本离线生成 PNG，音频在浏览器内实时合成。

## 1. 技术约定

| 项目 | 约定 |
|---|---|
| 逻辑分辨率 | **320×180**，最近邻放大 |
| 地图格 | **16×16** 像素 |
| 字体 | Fusion Pixel 12px（OFL）；中文字形 11×11，行高建议 14~16px |
| 调色板 | `tools/art/palette.py`（共享，**所有美术必须从中取色**） |
| 光源 | 左上方 |
| 描边 | 外描边用 `INK #120e1c` 或该材质最暗色；**禁止纯黑、禁止抗锯齿半透明像素**（特效/光晕除外） |
| 输出 | `assets/` 下 PNG + 同名 JSON 元数据；生成脚本放 `tools/art/` |

JSON 精灵表元数据统一格式：
```json
{ "frames": { "帧名": [x, y, w, h, anchorX, anchorY] }, "anims": { "动画名": [["帧名", 持续帧数], ...] } }
```
anchor 为该帧在画面中的“落点”（例如脚底中心），运行时 `draw(帧名, x, y)` 会让 (x,y) 对准锚点。

## 5. 剧情大纲（传统王子复仇记）

- **序章 庆典之夜**：丰收祭。国王对艾尔文说“明天我有话要对你说”。瓦尔德当众祝酒。深夜钟声大作，城门被内应打开，黑鹰军与北方士兵涌入。艾尔文冲向王座厅，看见瓦尔德的剑刺穿父王。父王临终：“走……活下去。”王冠滚落火中。格伦硬把王子拖进密道，赛琳同行，诺拉在城外林中接应。回望燃烧的王城，艾尔文立誓复仇。瓦尔德向全城宣布：王子弑父潜逃。
- **第一章 燃烧的边境村**：三天后，石溪村。追兵队长戈尔德以“窝藏弑父者”为名屠村。守备军士兵多兰拒绝命令，独自护住礼拜堂的村民。艾尔文不顾格伦劝阻冲进村子。战后：村民的感激与恐惧；艾尔文与格伦爆发冲突（“你为什么不让我回去救父王！”）。村长玛莎决定带村民随王子东逃。
- **第二章 断桥伏击**：黑水河石桥被敌军炸断，只剩北侧木桥与南侧浅滩。护送玛莎和难民过河。为钱给敌军当向导的盗贼希德盯上了收费站的宝箱。战后：希德入队；格伦不信任他（伙伴冲突的另一面）。难民在东岸村庄安顿。得知国王的忏悔神父——静语修道院的本笃院长——替国王保管着一封信，而瓦尔德的审讯官也正赶往那里。**反派幕间**：瓦尔德在王都广场处决“同党”，北方使节在侧。
- **第三章 沉默的修道院**：修道院已被审讯官摩根占领，修士被囚。救出地牢里的宫廷学徒米拉，击败驻军。战后：**父王真相**——院长交出国王亲笔信：国王早知瓦尔德勾结北方、知道自己被慢性下毒，并事先密令格伦“若有变故，带艾尔文走，不许他回头”；信里说“王冠不是奖赏，是重担……若瓦尔德篡位，你必须夺回它——不是为了我，是为了那些会在他手里死去的人”，并附有立储诏书与忠臣名单。米拉拿出御医的毒药账簿。艾尔文向格伦道歉，冲突和解。
- **第四章 风雪山隘**：带着诏书北上联络奥斯温伯爵，在霜牙关要塞被诺德兰军与黑鹰军封锁。战前**民众遭难**：一队难民在山道被屠，天马骑士薇拉拒绝继续执行命令。坚守要塞直到奥斯温援军到达（或击败格里姆）。战后：奥斯温伯爵率军抵达，承认艾尔文为王储；薇拉（若入队）揭露瓦尔德把北方行省许给诺德兰；瓦尔德将在三天后加冕礼上公开处决被俘的忠臣。
- **第五章 重返王城**：决战前夜营火，艾尔文对全军**动员**，与伙伴逐一交谈。黎明攻城：突破城门、庭院、大厅，直抵王座厅。与瓦尔德的首领对话。战后：瓦尔德败北，临死反扑，被艾尔文亲手斩杀——复仇完成；艾尔文从灰烬中拾回烧黑的王冠，决定就戴着它加冕，提醒自己它有多重。尾声：各角色结局（阵亡者有悼念）。

## 6. 剧情脚本格式（src/game/story/*.js，导出模板字符串）

```
# 注释
@bg 背景id | @bg map（显示当前地图） | @bg black
@music 曲目id | @music stop
@sfx 音效id
@wait 30
@shake 6
@flash white|red
@fadeout / @fadein
@chapter 第一章|燃烧的边境村
@show 角色id 位置 [表情]      位置：farleft left right farright
@hide 角色id | @hide all
@if 条件 / @elif 条件 / @else / @end
    条件：alive:id  dead:id  recruited:id  flag:名字  !前缀取反  mode:classic  mode:casual
@set 旗标名
名字：台词              （中文显示名，需在角色表里；可写 名字(表情)：台词）
显示名[id](表情)：台词   （显示名与头像不一致时，如“？？？[vera]：……”）
旁白：台词
```
表情：`normal` `smile` `angry` `sad` `surprise`（通用人物只有 normal）。
