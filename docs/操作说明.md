# 《灰烬王冠》操作说明

## 启动

- 双击根目录 `启动游戏.bat`（自动开服务器并打开浏览器），或双击 `灰烬王冠.html` 单文件版。
- 标题画面按任意键后出现菜单：开始游戏 / 继续游戏 / 读取存档 / 设置 / 操作说明 / 制作人员与素材 / 退出游戏。
- 开始游戏时依次选择 **难度**（简单 / 普通 / 困难）与 **模式**（休闲：伙伴倒下只撤退；经典：伙伴永久阵亡）。

## 一回合怎么玩

1. **选中蓝色的我方单位**：蓝色格子是能移动到的位置，红色格子是能攻击到的位置，绿色是杖的治疗范围。
2. **选择目的地**：光标移动时会显示路径箭头。也可以直接点击敌人，单位会自动走到能攻击它的位置。
3. **行动菜单**：攻击、杖、交谈、访问、开箱、开门、物品、交换、运输队（王子）、占领、撤离、待机。在执行动作之前按取消可以退回原位。
4. **攻击**：选武器后选目标，窗口会显示双方的 HP、伤害、命中、必杀、是否追击（×2）、能否反击，以及武器克制箭头。
5. 所有单位行动完会自动进入 **敌方回合**；也可以按 E 提前结束（还有人没动时会确认）。

画面四角会显示：光标处单位的信息、地形加成、胜利目标与“我方回合 · 第 N 回合”。这些窗口会自动避开光标和正在选择的目标。

## 规则速查

- **伤害** = 力量（魔法用魔力）+ 武器威力 − 对方防御（魔法看魔防）− 地形防御。
- **命中** = 武器命中 + 技巧×2 + 幸运÷2 − 对方回避（攻速×2 + 幸运 + 地形回避）。
- **必杀** = 武器必杀 + 技巧÷2 − 对方幸运，伤害 ×3；重甲的“坚壁”不会被必杀。
- **追击**：攻速比对方高 4 以上时攻击两次。攻速 = 速度 − 武器超重部分。
- **克制**：剑 > 斧 > 枪 > 剑，优势方威力 +1、命中 +15。
- **特效**：弓对飞行单位、斩马枪对骑兵、破甲锤对重甲、王家细剑/白鹿圣剑对骑兵与重甲，威力 ×3。
- **反击**：武器射程覆盖双方距离才能反击；弓打不到贴身的敌人，杖不能反击。
- **地形**：森林（防 +1、避 +20）、山地（防 +2、避 +30，骑兵不可进入）、要塞（防 +2、避 +20，每回合回复 20%），河流/高山/悬崖只有飞行单位能过。
- **增援**：出现前一回合会在地图上显示红色“!”并提示，出现的那一回合不会立刻行动。
- **村庄**：停在村口选择“访问”可获得道具；第一章的追兵会烧毁没被访问的村庄。
- **门与宝箱**：需要钥匙或盗贼希德。
- **交谈招募**：可以招募的人物头上会一直闪烁对话气泡。让艾尔文走到他旁边选择“交谈”：第一章多兰、第二章希德、第四章薇拉。第三章的米拉在地牢里，打开牢门即可救出。

## 成长与加点

- 攻击、击败敌人、用杖治疗都能获得经验，满 100 升级，并按“职业成长 + 个人成长”随机提升能力。
- 每次升级额外获得 **2 点潜能点**，在“部队 → 加点”（地图菜单或整备画面）里分配：
  - 职业专长能力（★）1 点 = +1，其余能力 2 点 = +1，HP 1 点 = +2；
  - 每项能力通过加点最多 +5（HP 最多 +10），不能超过职业上限；
  - 移动力 6 点 = +1，每人只能加一次；
  - “推荐加点”会按职业定位自动分配，确认前还能修改。

## 整备（第二章起每章开战前）

出击人员、调整站位、物品整理（装备 / 使用 / 存入运输队 / 交换）、商店（购买 / 半价出售）、部队 · 加点、查看目标、存档、设置。确认“出击”时会自动存档到“自动存档”位。

## 存档

- 3 个手动存档位；地图菜单（我方回合）或整备画面都能存档。
- 每章开战前自动存档；战败时可以“重新开始本章”或读档。
- “继续游戏”会读取最近的一个存档。

## 设置

音量（总 / 音乐 / 音效）、画面亮度、窗口/全屏、整数缩放、CRT 滤镜开关与强度、荧光与色偏、文字速度、战斗演出（完整侧视 / 简略地图）、游戏速度、回合结束确认、难度（从下一章开始生效）。所有设置即时预览并自动保存。
