## 本作原创素材

以下素材均由本项目的生成脚本原创绘制/合成，没有使用任何现成图片、音频或商业游戏资产（未拆取《火焰纹章》的立绘、地图、音乐等）。

| 类别 | 文件 | 生成方式 |
|---|---|---|
| 章节地图（5 张 × 3 帧动画 + 变化状态图） | `assets/maps/` | `tools/art/paint_map.py`：按关卡地形字符逐格绘制，自动拼接水岸、道路、墙体、山脉、屋顶 |
| 地图叠加特效（光标、范围格、路径箭头、预警、火焰烟雾、目标标记） | `assets/mapfx.png` | `tools/art/gen_mapfx.py` |
| 地图小人（16 种职业 × 4 种阵营色 × 待机/上/下/侧 行走） | `assets/units.png` | `tools/art/gen_units.py`：手绘式像素部件组合 |
| 物品与武器图标 | `assets/icons.png` | `tools/art/gen_icons.py` |
| 角色头像（19 人，多表情 + 口型 + 眨眼 + 小头像） | `assets/portraits.png` | `tools/art/gen_portraits.py`：矢量形状光栅化 + 分部位着色 + 描边 |
| 侧视战斗动画（26 组）、战斗特效、战斗背景与站台 | `assets/battle_*.png` | `tools/art/gen_battle.py`：部件骨骼木偶按关键帧摆姿势后 1 倍光栅化 |
| 剧情背景（18 张）、标题背景、Logo、图标 | `assets/bg/`、`assets/title_bg.png`、`assets/logo.png`、`assets/icon.png` | `tools/art/gen_backgrounds.py` + `tools/art/bgkit.py` |
| 音乐 14 首（11 首循环曲 + 3 首短曲） | `src/game/data/music.js` | 原创作曲，浏览器内由 `src/core/synth.js` 实时合成（方波/三角波/噪声 + 采样器风格音色），不含音频文件 |
| 音效 38 个 | `src/game/data/sfx.js` | 参数化合成（sfxr 式） |
| 剧情文本（约 7,800 字主线 + 分支） | `src/game/story/` | 原创 |
| 调色板 | `tools/art/palette.py` | 原创 |

## 构建工具（不随游戏分发）

- Python 3 + Pillow + numpy：生成美术素材。
- esbuild（MIT）：仅用于把源码打包成单文件版，产物中只包含本作代码。
