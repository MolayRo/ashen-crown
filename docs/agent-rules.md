# 协作规则（所有子任务必读）

项目：`E:\ai\ashen-crown` —— 《灰烬王冠》，GBA《火焰纹章》式中文战棋，浏览器运行。
先读 `docs/design.md`（规格、角色外观、职业、剧情大纲）和 `tools/art/palette.py`（主调色板）。

## 通用
- 只写入分配给你的路径；**不要修改** `docs/`、`tools/art/palette.py`、`src/core/`（除非任务明确分配）以及其他子任务的文件。
- 需要额外颜色时在你自己的脚本里定义，并保持与主调色板同一风格（饱和度、明度层次）。
- 环境：Windows 11，Python 3.13 + Pillow 12 + numpy 已装；Node 24 已装；用 Bash（Git Bash）或 PowerShell。
- 用 Write/Edit 工具写文件时，**不要写反斜杠 u 形式的 Unicode 转义**（工具会把它变成真实字符导致文件损坏），直接写字符本身；正则里尽量少用反斜杠。
- 美术：1 倍像素生成 PNG；另存放大预览到 `tools/art/preview/<你的模块>/`，用 Read 工具打开图片检查效果并反复迭代，直到达到 GBA《火焰纹章》的品质。
- 像素规范：只用调色板色；无抗锯齿半透明像素（特效光晕、范围格子除外）；外描边用 INK 或材质最暗色，禁止纯黑；光源左上；同类素材尺寸、视角、描边粗细一致。
- 效率：预览图不必每次都很大（缩放到能看清即可），合并多张到一张对比图再看，节约额度。
- 完成后给出 ≤300 字的中文汇报：产出文件、帧命名规则、集成时需要注意的事项、已知不足。
