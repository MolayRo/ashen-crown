# 灰烬王冠 · The Ashen Crown

GBA 点阵风格的中文回合制战棋游戏：王子复仇、夺回王国。五章完整战役，8 名可操控伙伴，侧视战斗演出，芯片音乐，CRT 滤镜。

## 开始游玩

**在线游玩**：<https://ashencrown.ya1om.com/>

**方式一（本地，推荐）**：双击项目根目录的 `启动游戏.bat`。它会在本机 5186 端口启动一个小服务器，并用默认浏览器打开 <http://localhost:5186/>。需要已安装 Python 3。关闭最小化的“Ashen Crown server”窗口即可停止服务器。

**方式二**：手动启动服务器后，在浏览器里打开 <http://localhost:5186/>：

```bash
python tools/devserver.py 5186
```

**方式三（免服务器）**：直接双击 `dist/ashen-crown.html`（本地执行 `node tools/build_single.mjs` 后根目录还会多一份 `灰烬王冠.html`）。这是把全部代码与素材打进一个文件的单文件版，可以拷到任何电脑上用浏览器打开。

> 第一次按键或点击后才会有声音（浏览器的自动播放限制）。推荐使用 Chrome / Edge 等新版浏览器。

## 内容一览

- **剧情**：序章 + 五章 + 结局，主线约 7,800 字（阅读约 20 分钟），伙伴阵亡或未招募时有分支台词，结局为阵亡者写了悼念。
- **五个关卡**：燃烧的边境村（击败首领、保护村庄）、断桥伏击（护送撤离）、沉默的修道院（救出囚犯并全灭）、风雪山隘（坚守 8 回合）、重返王城（击败篡位者并占领王座）。
- **8 名伙伴**：艾尔文（领主）、格伦（骑士）、诺拉（猎人）、赛琳（修女）、多兰（重甲骑士，第一章救援）、希德（盗贼，第二章交谈）、米拉（法师，第三章救出）、薇拉（天马骑士，第四章交谈）。
- **战棋规则**：移动/攻击范围、路径箭头、战斗预测、剑斧枪克制、弓对飞行特效、追击、必杀、反击、地形防御与回避、门/宝箱/村庄/增援预告、敌方 AI（进攻、守点、固守、支援、烧村、抢宝箱、占领）。
- **成长**：职业 + 个人成长率随机升级，每级 2 点潜能点可手动加点（专长能力更便宜、每项有上限、移动力仅能加一次），带推荐加点。
- **整备**：出击人员、调整站位、物品整理、运输队、交换、商店、部队加点、存档。
- **模式与难度**：休闲 / 经典（永久阵亡）；简单 / 普通 / 困难（敌人等级与能力、兵力配置、AI 倾向、资源都会变化）。
- **存档**：3 个手动存档位 + 每章开战前自动存档；地图上（我方回合）可随时存档。
- **设置**：总/音乐/音效音量、亮度、窗口/全屏、整数缩放、CRT 开关与强度、荧光与色偏、文字速度、战斗演出（完整/简略）、游戏速度、回合结束确认、难度（下一章生效）。设置即时生效并自动保存。

## 项目结构

```
index.html            页面入口（ES Module）
src/core/             引擎：渲染与 CRT 着色器、输入、字体、窗口、音频（合成器 + Worker）、存储
src/game/             纯逻辑（可在 Node 中运行）：规则、寻路、战斗状态、AI、战役流程、存档、自动操作
src/game/data/        职业、武器道具、角色、地形、五章关卡数据、曲目与音效乐谱
src/game/story/       全部剧情脚本（自定义文本格式）
src/scenes/           标题、新游戏、剧情、整备、地图、侧视战斗、角色、物品、设置、存读档、结局等场景
assets/               程序生成的像素素材（地图、头像、小人、战斗动画、背景、图标、字库）
tools/art/            生成全部美术的 Python 脚本
tools/tests/          自动测试（数据校验、战役模拟）
tools/build_single.mjs  打包单文件版
docs/                 操作说明、素材来源与许可、测试报告
licenses/             字体许可证
```

## 开发命令

```bash
node tools/tests/validate.mjs            # 数据一致性：剧情引用、头像/动画/图标/曲目/音效是否齐全
node tools/check_maps.mjs                # 地图检查并导出给地图绘制器
node tools/story_stats.mjs               # 剧情字数与格式检查
node tools/tests/sim.mjs normal 10 classic --retries=2   # 无头战役模拟（我方由 AI 代打）
python tools/build_font.py               # 修改文本后重建点阵字库
python tools/art/paint_map.py            # 重新绘制章节地图
node tools/build_single.mjs              # 生成单文件版
```

浏览器调试入口：`?debug=autotest`（从新游戏自动打到结局）、`?debug=battle&ch=0`（直接进入第 N 章战斗，0 起）、`?debug=prep&ch=2`。

部署：`bash deploy.sh` 把 `index.html`、`src/`、`assets/` 同步到服务器 `/var/www/ashencrown`（nginx + certbot，首次运行会自动装站点配置并申请证书）。
